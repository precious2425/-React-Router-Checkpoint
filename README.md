# MovieHub - Router Checkpoint

This project implements the movie-app router checkpoint.

## Requirements implemented

- Movies contain a description and embedded YouTube trailer link.
- Clicking a movie card routes to `/movie/:id`.
- The movie details page displays the description and trailer.
- A Back to Home link returns to `/`.
- React Router is used for navigation.

## Run the project

Open the project folder in VS Code, then open the terminal and run:

```bash
npm install
npm run dev
```

Vite will provide a local address such as `http://localhost:5173`.

## Build for submission

```bash
npm run build
```

Then push the project to a new GitHub repository using the checkpoint name required by your instructor.
